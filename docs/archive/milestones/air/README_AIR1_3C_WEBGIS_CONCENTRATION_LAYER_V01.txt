AIR-1.3C Web GIS Concentration Layer v0.1

Adds frontend visualization preparation for CAMS canonical fields.

Features:
- CAMS grid normalization
- heatmap point conversion
- pollutant metadata
- legend model

Supported:
PM2.5
PM10
NO2
SO2
O3
Dust

Semantics:
CAMS = model forecast, not observation.

Not included:
- dispersion
- plume forecast
- impact model
